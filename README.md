# 👤 Meu Perfil - Página de Apresentação Pessoal

Este repositório contém um projeto web simples e responsivo desenvolvido com **HTML5** e **CSS3**, criado para exibir um perfil pessoal profissional/estudantil.

---

## 🚀 Tecnologias Utilizadas

*   **HTML5:** Estruturação semântica da página (tabelas, seções, cabeçalhos, rodapé e links).
*   **CSS3:** Estilização visual (cores, fontes, bordas, dimensionamento com `vh` e formatação de elementos).

---

## 📁 Estrutura de Arquivos

O projeto é composto por três arquivos principais na raiz:

```text
├── index.html    # Arquivo principal contendo a estrutura da página
├── index.css     # Folha de estilos responsável pelo design e layout
└── foto.jpg      # Imagem de perfil exibida na página
```

---

## 🎨 Funcionalidades da Página

*   **Cabeçalho e Rodapé Customizados:** Identificação clara do projeto com cores sóbrias e elegantes.
*   **Seção de Apresentação:** Inclusão de foto de perfil estilizada com bordas arredondadas e moldura.
*   **Biografia e Interesses:** Breve descrição acadêmica/profissional e lista de hobbies.
*   **Links Úteis:** Redirecionamento para a página oficial da instituição de ensino.

---

## 💻 Como Executar o Projeto Localmente

Para rodar este projeto na sua máquina, siga os passos abaixo:

1. **Clone este repositório** ou faça o download dos arquivos compactados:
   ```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
   ```
2. Certifique-se de que os arquivos `index.html`, `index.css` e `foto.jpg` estão na mesma pasta.
3. Dê um duplo clique no arquivo **`index.html`** ou abra-o utilizando o seu navegador web favorito (Chrome, Firefox, Edge, etc.).
